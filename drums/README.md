# Drum samples

Trimmed, faded and MP3-encoded excerpts from **Virtuosity Drums**
(https://github.com/studiorack/virtuosity-drums), recorded at Virtuosity Musical
Instruments in Boston, MA, performed by Austin McMahon.

Released under **CC0 1.0 Universal** (public domain dedication) by the original authors.

Used here: ride (overhead mics), kick (kick mic), snare center hits (overhead + snare mic),
hi-hat pedal (overheads), crash (overheads).

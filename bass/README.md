# Bass samples

Trimmed, level-matched and MP3-encoded excerpts of the **Solo Contrabass, Pizzicato**
patch from **VSCO 2 Community Edition** by Versilian Studios
(https://github.com/sgossner/VSCO-2-CE).

Released under **CC0 1.0 Universal** (public domain dedication) by the original authors.

File names are `bass_<MIDI note>_<round robin>.mp3`. The source files name notes two
octaves lower than scientific pitch (their "E0" is the bass's open E, MIDI 28).
Per-sample tuning offsets measured from the recordings are stored in `index.html`
and corrected at playback.

# Bass samples: "Upright (studio)"

Trimmed, level-matched, mono MP3 excerpts (E1–Ab3, one file per note) of the
**Acoustic Bass** preset from the **MusyngKite** General MIDI SoundFont, as rendered to
per-note audio by the midi-js-soundfonts project
(https://github.com/gleitz/midi-js-soundfonts).

MusyngKite is licensed under **Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0)**:
https://creativecommons.org/licenses/by-sa/3.0/ . These adapted samples are distributed
under the same license. Changes: trimmed, faded, mono, level-matched, MP3-encoded.
Per-sample tuning offsets are stored in `index.html` and corrected at playback.
